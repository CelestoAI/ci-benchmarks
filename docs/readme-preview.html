Celesto CI Benchmark

Open benchmarks for GitHub Actions runners. Real builds of public projects, pinned to a commit, run on a schedule. Every workflow, script and raw result is in this repository.

Latest results

p50 (median) workload and queue times for each provider. Lower is faster.

SuiteWorkload
RustCold cargo test and clippy of spotify-player
NodeCold bun install and typecheck of opencode
Dockerdocker buildx build of PostHog's production image, no cache
CacheSave and restore a 4 GiB file with actions/cache
QueueWait from job creation to runner start when 15 jobs are queued at once

All runners have 4 vCPU (x64). Celesto results come from this repository's runner suites. Other providers' results come from the runs-on.com public benchmark data, which uses the same workloads and settings. Both include the last 30 days of runs. Updated daily.
